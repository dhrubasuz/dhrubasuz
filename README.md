# Dhruba Poudel

**Business Systems Analyst | Software development, automation, data and IT operations**

I turn operational requirements into practical applications, validated data workflows and clear reporting. My work connects software development with business systems analysis, technical troubleshooting and dependable service delivery.

## What I work on

- **Web and software development:** PHP, JavaScript, React, Node.js, HTML/CSS, SQL/MySQL and WordPress.
- **WordPress and commerce:** custom theme and plugin development, API integration and WooCommerce.
- **Branding and interface design:** logo design, visual identities and responsive websites.
- **Automation and data:** Excel/VBA, CSV transformation, data mapping, validation, exception handling and reconciliation.
- **Reporting:** operational dashboards, source-data checks, reporting definitions and clear explanations of gaps and exceptions.
- **Technical delivery:** requirements, testing, user acceptance, Git, Jira, documentation and handover.
- **IT operations and identity:** Microsoft 365 and Cloud PC service coordination, access requests and Microsoft Entra ID SSO requirements.

I have helped lead Help Desk operations through changing workloads and contributed to a unified support and ticketing process. I work with users, developers and managed service providers to clarify ownership, prioritise issues and follow changes through testing and handover.
